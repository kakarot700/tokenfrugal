# Actual local inference validation — 16 November 2026
Qwen2.5-Coder-1.5B-Instruct GGUF Q4_K_M ran locally with llama-cpp-python. No paid API, scripted responses or human patch was used in this run. Seven real model calls consumed 4,931 reported prompt+completion tokens and repaired the inventory fixture. A separate unittest invocation passed both unchanged fixture tests. The model changed only inventory/total.py. Inference used one CPU thread (the host has a two-CPU cgroup quota).

This is one small fixture, not a general coding benchmark or a competitive token-savings measurement. Earlier 1,462-token scripted demo is an estimate and is not this result. The guard and JSON prompt were selected after failed local trials; the successful result is not a blind held-out evaluation. Full result, transcript, audit and reproduction harness accompany this note. Reproduction requires a separate free GGUF download and llama-cpp-python installation; edit model_path in the harness to your downloaded model. Existing execution safety limitations still apply: use an isolated disposable environment, not an OS sandbox claim.
